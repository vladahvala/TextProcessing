# Лабораторна робота №3 — обробка тексту підручника (Haskell)

**Варіант 16.** У деякому реченні тексту слова заданої довжини замінити вказаним
підрядком, довжина якого може не збігатися з довжиною слова.

## Структура

| Файл | Зміст |
|---|---|
| `TextTypes.hs` | Типи: `Symbol` (Символ), `Word` (Слово), `Punctuation` (Розділовий знак), `Element` (елемент речення: слово / знак / пробіл), `Sentence` (Речення), `Text` (Текст); перетворення назад у рядок |
| `TextParser.hs` | Заміна табуляцій і послідовностей пробілів одним пробілом, розбиття на слова, розділові знаки та речення |
| `Main.hs` | Розв'язок варіанта 16 і діалог з користувачем |
| `textbook.txt` | Приклад тексту підручника |

## Як працює

1. Текст читається з файлу (UTF-8). Табуляції, переходи рядка й кілька пробілів
   поспіль замінюються одним пробілом.
2. Текст розбивається на речення: речення закінчується знаком `.`, `!`, `?` або `…`,
   після якого йде пробіл чи кінець тексту (тому `3.14` або `obj.method` речення
   не розривають). Порожній рядок (новий абзац) теж завершує речення, щоб заголовки
   без крапки не зливалися з наступним текстом.
3. Речення розбивається на слова, розділові знаки та пробіли.
4. Користувач обирає номер речення, довжину слова та підрядок. Усі слова цієї
   довжини в реченні замінюються підрядком. Довжина слова — кількість букв і цифр
   (апостроф і дефіс не рахуються).
5. Виводяться речення до і після заміни, весь текст після заміни; результат
   також записується у `result.txt`.

## Запуск (Windows, PowerShell)

```
chcp 65001
cabal run text-processing
```

`chcp 65001` перемикає консоль на UTF-8, інакше українські букви відображатимуться
неправильно. Якщо після цього введений українською підрядок все одно читається
некоректно, запустіть так:

```
cabal run text-processing -- +RTS --io-manager=native
```
